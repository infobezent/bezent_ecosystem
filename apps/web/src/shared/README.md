# shared/

Generic, business-agnostic hooks/utils/types/constants usable by any part of
the frontend (`app`, `platform`, `design-system`, or any module). Contains
no business logic and no knowledge of HRMS or any other business
application.

Empty in Phase 0 (`hooks/`, `utils/`, `types/`, `constants/`). Add a file
only when a concrete cross-cutting need arises.
